# Change Record 0003 — CRP v0.2 Derived from CSTR

**Date:** 2026-09-28  
**Area:** Cognitive Representation Protocol  
**Status:** Proposed / documented  
**Branch:** feature/crp-v0.1

## Context

CSTR v0.1 established the authoritative historical record for governed cognitive transitions.

CRP v0.1 represented observations, interpretations, inferences, uncertainty, proposed cognitive updates, governance metadata, and provenance, but did not explicitly represent the predecessor state context or first-class evidence/proposal structure required to support the state-transition architecture.

## Decision

Introduce CRP v0.2 as a representation layer derived from the Cognitive State Transition Model and CSTR.

CRP v0.2 adds:

- explicit predecessor state context
- first-class evidence objects
- explicit cognitive proposal
- governance evaluation context
- optional CSTR transition reference
- richer provenance

## Critical Boundary

CRP v0.2 does not become the Cognitive State Transition Record.

The distinction is:

CRP = information presented for cognitive evaluation.

CSTR = authoritative record of the governed transition that actually occurred.

The Cognitive Kernel remains responsible for executing persistent state changes.

## No-Guessing

The v0.2 semantic layer requires:

- inference bases to reference evidence
- proposal evidence to reference evidence
- unknown observations to remain free of observed facts
- committed transition references to require approved governance
- no direct state commitment from representation alone

## Important Design Decision

A CRP candidate may legitimately contain no proposal.

This represents experiences that are interpreted but do not currently justify a cognitive proposal.

Therefore:

Experience != Proposal != Commitment

## Consequence

CRP v0.2 is now sufficiently structured to support future transition evaluation while remaining independent from PCG and CSTR implementation.

The next architectural work is the Cognitive Kernel transition executor, not further expansion of CRP fields unless a concrete transition requirement demonstrates the need.
