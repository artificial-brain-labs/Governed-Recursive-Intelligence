# Change Record 0007 — CRP v0.2 Governed Transition Adapter

**Date:** 2026-09-28
**Area:** CRP / governance / kernel integration
**Status:** Proposed / documented
**Branch:** feature/crp-v0.1

## Context

GRI now has CRP v0.2, Governance v0.1, the Cognitive Kernel v0.1, and an end-to-end governed transition pipeline.

A controlled adapter is required to connect CRP to that pipeline without allowing the representation layer to become an authorization mechanism.

## Decision

Introduce a strict CRP v0.2 adapter.

The adapter:
- performs structural validation
- performs semantic validation
- verifies predecessor state context
- extracts explicit evidence references
- extracts the proposal
- invokes actual Governance
- invokes the Cognitive Kernel
- preserves CRP provenance in the resulting CSTR

## Critical Architecture Decision

The governance status embedded inside a CRP event is NOT trusted as execution authorization.

Actual Governance is always re-run.

Therefore:

CRP governance metadata != authoritative governance decision

## State Continuity

The adapter requires CRP state_context to match the supplied CognitiveState state_id and state_version.

A mismatch is rejected before execution.

## Consequence

CRP can now enter the executable GRI pipeline without collapsing the boundaries between representation, authorization, execution, and historical record.

The next major architectural concern is persistent CSTR/PCG storage and state-version continuity beyond an in-memory prototype.
